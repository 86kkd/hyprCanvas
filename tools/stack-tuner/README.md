# 堆叠比例调节台

在项目根目录运行：

```sh
python3 tools/stack-tuner/server.py
```

打开 http://127.0.0.1:8765 。无需安装依赖。服务仅监听本机。

顶部「卡片宽高缩放倍率」调整垂直于堆叠轴的尺寸：纵向堆叠调宽度、横向堆叠调高度。三个参数：
- 主窗口：相对预览区域（0.1×–2×，默认 1×）。
- 次窗口：相对主窗口（0.1×–1×，默认 0.95×），仍指上次聚焦窗口。
- 其他窗口：逐层递减倍率（0.1×–1×，默认 0.9×）。从次窗口尺寸出发，在主窗口两侧分别按其他窗口由近到远的序号 k 计算：主倍率 × 次倍率 × 递减倍率的 k 次方。次窗口不占其他窗口的层数；1× 表示不递减。

例如 G 主、F 次时，G → F → E → D → C → B → A 为 100% / 95% / 85.5% / 77.0% / 69.3% / 62.3% / 56.1%。卡片居中，超出区域部分裁切。侧栏显示每张卡的实际尺寸百分比。
参数保存在 cross_axis（basis=progressive_cross_axis）的 main_scale / secondary_relative_scale / others_decay 中。旧草稿保留露出参数及有效主倍率，次倍率与递减倍率采用新默认值。

下方「堆叠轴露出比例」保留原有的露出长度调节。拖动滑块或输入百分比，点击窗口、导航按钮或在预览内按方向键切换。比例指沿堆叠轴的**可见长度**，合计始终为 100%；其他窗口均分总占比。主窗口完整显示，次窗口为上次聚焦的窗口，保留原始上下顺序，到边界不循环。预览不添加动画缓动。

“载入当前插件比例”和默认值均为已选定的 61.8% / 19.1% / 19.1%。其他窗口均分固定的 19.1% 总占比。

修改自动保存在浏览器草稿中；只有点击 **保存最终参数** 才会写入 `tools/stack-tuner/final-ratios.json`。调好保存后告诉我，便可按该文件修改插件。网页不会修改或重载插件。重置只修改草稿，不删除已保存文件。复制/导出使用当前预览数值。

这是几何比例预览；真实桌面的动画和鼠标随焦点行为仍需在插件中验证。预览窗口用点击切换，避免调参过程中鼠标悬停引起跳动。像素数按设置的轴长度计算，画布会随浏览器缩放。

验证：`node --test tools/stack-tuner/model.test.mjs`。设计与浏览器验证记录见 [design/verification.md](design/verification.md)。
