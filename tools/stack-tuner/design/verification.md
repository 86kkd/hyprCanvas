# 设计与验证

使用内置 Imagegen 生成的参考图：`concept.png`。页面使用 HTML/CSS 实现，没有将图片当作界面。

对照桌面截图检查：
- 保留深灰底色、左侧参数面板和右侧大预览的布局。
- 保留紫色主窗口、绿色次窗口、黄色其他区域的配色。
- 保留顶部保存操作和底部参数汇总。
- 滑块、数字输入、预设和方向选择均使用真实可操作控件。
- 预览保持原始窗口顺序，支持主次窗口交换。
- 手机端面板垂直排列，390 px 宽度无水平溢出。

必要差异：文案明确比例按可见轴长度计算；标尺按实际窗口位置分别标注，其他窗口不是全部聚集在底部；增加当前插件比例入口、每个窄边像素值和保存状态。小比例可能使标签不完整，这是窄边尺寸不足的真实预览，界面同时提示提高占比。字号及间距按实际浏览器字体调整。没有加入窗口动画曲线。

验证完成：Node 模型测试覆盖 20,000 次比例调节和 3–10 个窗口的所有不同焦点组合；Chromium 检查比例输入、焦点边界、数量、方向、保存和刷新、非法参数拒绝、外部 Origin 拒绝、手机宽度、JSON 下载。浏览器无脚本异常。保存测试使用 /tmp 下的独立文件，没有生成用户最终参数。
