# 堆叠调节台设计

参考：concept.png（内置 Image Gen 生成，完整桌面调节台概念）。

- 石墨黑背景 #111215，面板 #1e2026，边框 #343741。
- 主窗口淡紫 #ba94f4、次窗口薄荷 #a5e8cb、其他窄边琥珀 #f3ce7e。
- 顶栏 72px；桌面左侧约320px参数栏、右侧预览与最终参数栏。
- UI 字体系统 sans，标题20px，控件14px；圆角8px，克制阴影。
- 文字与交互全部由 HTML/CSS/JS 实现，概念图不作为界面背景。
- 已确定文案：HyprCanvas、堆叠调节台、重置、保存最终参数、可见区域比例、主窗口、次窗口、其他窗口 · 合计、快速预设、预览设置、窗口数量、堆叠方向、纵向、横向、预览高度、窗口标签、区域标尺、实时预览、上一个、下一个、最终参数、复制参数、导出 JSON。
- 必要的功能修正：将“面积”明确为沿堆叠方向的可见长度；标尺按真实顺序显示每个窄边，而非把所有窄边画在底部；显示每个窄边实际像素、保存状态；增加“载入当前插件比例”用于比较当前实现。
- 响应式：窄屏先参数后预览，控件不溢出；方向切换只是预览方向，比例策略对两种模式通用。
- 不添加自定义缓动曲线；切换预览即时更新，保持文件原顺序。
